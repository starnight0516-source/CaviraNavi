# Cavira 智行導航 (路瑞寶 6350 + Foxtron Cavira 專用)

## 雲端自動打包 APK 步驟
1. 在 GitHub 建立一個新的 Repository（例如 `CaviraNavi`）。
2. 將本壓縮檔解壓縮後的所有檔案（含 `.github/workflows/build-apk.yml`）上傳至該 Repository。
3. 上傳完成後，點選上方 **Actions** 分頁，等待 `Build CaviraNavi APK` 執行完成（約 2 分鐘）。
4. 點進該次執行紀錄，在最下方 **Artifacts** 區塊下載 `CaviraNavi-6350-APK`，解壓縮即可取得 `CaviraNavi-6350.apk`。
